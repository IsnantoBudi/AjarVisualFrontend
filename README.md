#  AjarVisual Frontend

> UI untuk platform generator soal SD berbasis AI  dibangun dengan Next.js 14, Tailwind CSS, dan design system "Ajar Playful Learning" dari Google Stitch.

## Tech Stack

| Layer | Teknologi | Keterangan |
|-------|-----------|------------|
| Framework | **Next.js 14** | App Router, SSR, file-based routing |
| Language | **TypeScript** | Type safety end-to-end |
| Styling | **Tailwind CSS** | Utility-first, konfigurasi custom design token |
| Font | **Plus Jakarta Sans** | Headlines  modern, geometric |
| Font | **Be Vietnam Pro** | Body text  legible, approachable |
| Design System | **Ajar Playful Learning** | Dibuat via Google Stitch |
| Image | **Pollinations.ai** | AI image generation, tanpa API key |

---

## Struktur Direktori

```
frontend/
 app/
    layout.tsx           # Root layout, font loading, metadata
    globals.css          # Design tokens, utility classes, @media print
    page.tsx             # Landing page
    generate/
       page.tsx         # Generator dashboard
    preview/
       page.tsx         # Worksheet preview + print
    history/

 .env.local               # Environment variables
 tailwind.config.ts       # Design tokens extension

```

## Setup & Instalasi

### Prerequisites
- **Node.js 18+**  [download](https://nodejs.org)
- **npm** atau **pnpm**
- Backend AjarVisual berjalan di port `8080`

### 1. Masuk ke folder frontend

```bash
cd frontend
```

### 2. Install dependencies

```bash
npm install
```

### 3. Buat file `.env.local`

```env
NEXT_PUBLIC_API_URL=http://localhost:8080
```

### 4. Jalankan development server

```bash
npm run dev
```

Buka **http://localhost:3000**

## Halaman & Fitur

### `/`  Landing Page
- Hero section dengan gradient biru + ilustrasi emoji
- Feature cards: Generate Soal, Auto-Illustration, Mode Cetak, Riwayat
- How it works steps (0104)
- CTA bottom section
- Footer credit

- Grid worksheet cards dari TiDB Cloud

## Design System

Design diimplementasikan dari **"Ajar Playful Learning"** (Google Stitch) dengan prinsip:

### Color Tokens
```css
--color-primary: #005caa;
--color-primary-light: #5aa2ff;
--color-primary-brand: #1976D2;
--color-secondary: #FFC107;     /* sunny yellow */
--color-tertiary: #4CAF50;      /* fresh green */
--color-bg: #f5f6f7;
--color-surface: #ffffff;
--color-surface-low: #eff1f2;
--color-on-surface: #2c2f30;
```

### Prinsip Desain
- **No-Line Rule**  pemisahan konten pakai background shift, bukan border
- **Glassmorphism**  navbar: `backdrop-filter: blur(12px)` + 75% opacity
- **Gradient CTA**  button dan hero pakai `linear-gradient(135deg, #005caa, #5aa2ff)`
- **Pill Radius**  semua button menggunakan `border-radius: 9999px`
- **Ambient Shadow**  shadow besar dan blur untuk efek "floating"

### Typography
```css
/* Headlines */
font-family: "Plus Jakarta Sans", sans-serif;

/* Body */
font-family: "Be Vietnam Pro", sans-serif;
```

## Custom Components

### `<ProgressBloom />`
Animasi loading khas AjarVisual  5 lingkaran bertumbuh (bloom) dengan warna biru dan kuning bergantian.

```tsx
<ProgressBloom message="Sedang membuat soal ajaib..." />
```

### `<QuestionCard />`
```tsx
<QuestionCard
  soal={soalData}
  index={0}
  onImageChange={(index, newUrl) => handleImageChange(index, newUrl)}
/>
```

Fitur:
- Auto fallback emoji `` jika gambar gagal load
- State interaktif untuk pilihan jawaban (klik untuk cek jawaban)
- Tombol Ganti Gambar dengan loading state

### `<NavBar />`
- Fixed position, glassmorphism styling
- Active state detection via `usePathname()`
- Hidden saat `@media print`

## API Client (`lib/api.ts`)

Semua fetch ke backend ter-type dengan TypeScript interface:

```ts
// Generate worksheet
const result = await generateWorksheet({ topik, kelas, jumlah_soal });

// Ambil riwayat
const list = await getHistory();

// Regenerate gambar
const newUrl = await regenerateImage(imagePrompt);

// Hapus
await deleteWorksheet(id);
```

## Print Mode (A4)

Dikontrol via CSS `@media print`:

```css
@media print {
  .no-print { display: none !important; } /* Sembunyikan navbar, fab, dll */
  .print-page { width: 210mm; padding: 20mm; }
  .question-card { page-break-inside: avoid; }
}
```

Gunakan **Ctrl+P** atau klik tombol **" Siap Cetak (A4)"** di halaman preview.

## Troubleshooting

| Masalah | Solusi |
|---------|--------|
| `EADDRINUSE port 8080` | Ganti port dengan `npm run dev` (sudah fix ke 3000) |
| Gambar tidak muncul | Pollinations.ai bisa lambat  tunggu 510 detik, atau klik "Ganti Gambar" |
| Halaman preview kosong | Pastikan sudah generate soal dulu dari `/generate` |
| API tidak konek | Cek backend berjalan di `:8080` dan `NEXT_PUBLIC_API_URL` di `.env.local` |
| Font tidak load | Pastikan koneksi internet aktif (font di-serve dari Google Fonts) |
